[Table-Video SOP](https://github.com/duoduoler-ops/Table-VideoSOP) 是一套公开的视频制作资料包，处理的是「文案和配音已经定下来之后」那一段：怎样让编程助手按同一套规则，把配音做成画面。默认路线是 [Remotion](https://www.remotion.dev/docs) 加 FFmpeg。

它适合人声解说是主线的视频——科普、观点、产品演示。分工在开头就划清了：你定内容、定风格、决定用哪一版；Agent 做规划、动画、剪辑和检查；生图、生视频由你自己在选定的工具里完成。

仓库里没有 demo、工程和素材，只有 SOP 文档、规则、经验文件、模板和可复制的提示词。它是一套方法，不是能直接跑出成片的项目。

<!--more-->

## 一条片子怎么走完

前提是文案确认、配音录好。之后所有画面、音效、字幕都以这条配音的时间为基准。

```text
确认稿件与配音 → 制作大段表 → 镜头剧本（人工审） → 分段设计图（人工审）
→ 分段制作 → 全片视觉确认 → 总装 → 音效与字幕 → 封面与发布材料
```

三份长期维护的文件把「顺序、路由、外观」分开：

- **SOP**：写制作顺序，就是上面这条链。
- **`AGENTS.md`**：任务路由。告诉助手做某类任务前读哪份经验，并写下容易漏的检查点，比如制作动画时记住关键动作的时间，方便之后配音效。这是[给编程助手看的项目约定](https://agents.md)，具体加载行为仍取决于使用的工具。
- **`DESIGN.md`**：画面规则。记录颜色、字体、间距、组件与动效选择；可参考 [Google Labs 的格式](https://github.com/google-labs-code/design.md)。同一个系列沿用同一份基准，不让每段镜头重新猜风格。

每期另有一份制作大段表。它不按固定秒数或「一句一镜」切，而按叙事任务、视觉关系、技术路线或风险变化划段，每段回答三件事：这段配音已经说了什么、画面必须补上配音里没有的哪些信息、屏幕上真正需要留下的文字是什么。「画面必须新增什么」这一列最难写，也是返工最多的来源。画面用来增强配音表达，不是把台词再打一遍；整段只是把字打出来再让它飞来飞去，和做 PPT 没区别。

制作工具可以分开选：Remotion 用代码描述动画，[FFmpeg](https://ffmpeg.org/about.html) 负责拼接和合成，录屏与素材生成使用各自合适的工具。这个资料包并不替你提供生图、生视频服务，素材要另行准备，相关模型与软件费用也另算。

Remotion 的免费使用有组织规模等条件，商业团队先看对应许可；不要把源码公开理解成任何规模都免费。换工具时先确认它能做哪种画面，不把时间线剪辑器当成三维动画引擎。

## 开工前先定设计规则

动工第一件事不是做视频，而是用两轮测试把设计规则定下来。

**静态测试**比较背景色、卡片倒角、字体、IP 角色放进画面后的协调度：直接让 Agent 出设计图，用眼睛对比；先去设计网站找参考图丢给 Agent，再让它微调，比空口描述有效。

**动态测试**看图形怎样变化与相互影响：方块怎样变成电脑，小球碰撞后另一个物体有没有反馈，主动作停下后附属物怎样收住。可以借动画十二原则中的蓄力、跟随、缓入缓出等概念，但要落实到具体动作，不只给助手一个术语。

两轮都满意后，让 Agent 把结果写成 `DESIGN.md`，作为整个系列的风格基准。没测过、没确认的部分写「待定」，别把静态确认当成动态也确认了。

流程里留了两处刻意的人工关卡：每段的镜头剧本和设计图先给人审，确认后才开始做视频；只有确实没做过的新做法（新镜头方式、空间处理、角色互动、转场）才先做几秒带配音的样片，同类段落直接对标已确认的片子。跳过设计确认直接出片，后面一旦要大改，token 消耗顶不住。

音效想对得准，就在做动画时记录动作时间。例如以本镜头起点为零，标出 `SFX @ 00:01.250`，注明是碰撞还是按钮触发；持续声音另写起止区间，后期不必凭感觉重新找点。

## 怎么判断每步真的做完了

各段确认采用后接进唯一主工程，生成审片文件看语义、可读性、段间衔接和遮挡；画面锁定后再做音效、字幕、封面。交付后复盘一次，用原话记返工，区分「规则没写」和「写了没执行」。

每段都要能对回对应的配音、设计图和采用版本。先检查声音与稿件是否一致，再检查画面有没有新增信息；有音频文件、有动画工程，都不等于两者已经正确对齐。

## 边界

**时间线定下来就不好改。** 整套流程以最初的配音为基准，后期也能小改配音，但不如在剪映、PR 里直接拖时间线方便：时间线一动，动画、音效、字幕都要重新对齐，相关画面还要重渲。适合在确定好的时间线上做内容，不适合频繁调整剪辑结构。

**流程文件不等于现成产线。** 换系统、编程助手或素材工具时，先跑一个带配音的短段落，确认取材、渲染与拼接都能接上，再扩大制作范围。
