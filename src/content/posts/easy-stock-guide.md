Easy Stock 是一款面向个人的 A 股研究桌面应用。它把行情、财经资讯、市场作者的文章和 AI 分析放在同一个窗口里，帮助使用者整理材料、比较观点，并保存自己的研究记录。[2]

如果你经常在行情软件、资讯网页和聊天助手之间切换，收盘后还要自己拼一份复盘，它就是为这类重复工作准备的。它的主要作用是组织研究流程，不是提供一个保证盈利的“AI 股神”。项目也明确把自身定位为学习、研究和信息整理工具。[2]

<!--more-->

## 用一次盘后复盘认识它

假设你收盘后想弄清楚：今天哪些方向受到关注，不同作者为什么得出不同判断，明天又该核对哪些条件。

平时，你可能先看指数和板块，再打开几位作者的文章，把有用段落复制到笔记里，最后交给 AI 总结。Easy Stock 希望把这些步骤接起来：[2]

```text
查看行情和题材 → 收集相关原文 → 整理共识与分歧 → 留下待验证的问题
```

这里的“题材”，可以理解成市场正在讨论的一组行业、事件或概念。软件不只展示一篇文章，而是把行情背景、文章来源和后续研究放在一起。

### 先看市场，再读观点

行情总览把指数、新闻快讯、行业资金、题材和公告等信息放进同一个入口，并保留数据来源与抓取时间。[2] 这样读一段观点时，可以先问：它针对的是哪一天、哪种市场情况，使用的数据有没有过时？

这不意味着多个来源一定完全一致。数据可能延迟、缺失或降级，更新时间仍然需要看，不能把一个漂亮的界面当作数据已经正确的证明。

### 把散落的文章整理成一份可回查的材料

项目提供“大 V 自动复盘”：按配置收集雪球、淘股吧等渠道的文章，去重、归档，再整理各位作者的观点及共同关注方向、主要分歧和后续观察条件。[2]

例如，可以把下面这段话当作研究任务说明，而不是软件的特殊命令：

> 整理今天收集到的复盘文章。分别列出共同观点和主要分歧，保留对应原文，再写清下一交易日需要观察什么；不要把作者的猜测改写成确定事实。

“很多人都这么说”也不等于结论成立。几篇文章可能引用了同一条消息，AI 还可能把不同人的条件判断压成一句笼统结论。原文入口比一句流畅的总结更重要。

### 从市场概况继续到个股研究

项目把个股研究分成无需模型的量化速览，以及不同深度的 AI 研判。[2] “量化”在这里可以先理解为用程序计算和整理行情指标；AI 再围绕这些材料解释逻辑、比较支持与反对证据。

它还提供持仓巡检和优化分析，把单只股票的研究放回一个组合里讨论。[2] 但评分只是当前材料下的一种研究评价，不是收益率或胜率。文档也说明，使用建议方案发起新巡检不会自动下单或修改实际持仓。[2]

## 它背后用了哪些技术

从使用者角度看，这是一个桌面程序；从开发角度看，它把几个职责不同的部分组合在一起：[2]

| 部分 | 负责什么 |
| --- | --- |
| Electron | 提供桌面窗口，并衔接本地程序、浏览器和文件能力 |
| React 与 TypeScript | 构建行情、文章、报告等操作界面 |
| Go 后端 | 采集和整理数据，执行计算，安排研究任务 |
| SQLite | 在本机保存文章、研究记录、历史与任务进度 |
| Hermes 或 Codex 运行时 | 按所选配置执行 AI 研究、工具调用和会话任务 |

理解它的关键不是记住这张技术栈表，而是分清两种工作：**数据服务先组织材料，AI 再基于材料解释和分析。** 项目并不是把几串股票价格直接塞进聊天框，就把模型回复当成全部研究结果。[2]

另一个值得注意的设计是保存中间进度。文档描述，部分研究任务可以在条件满足时继续缺失阶段，也会复用仍有效的已有报告，减少整套流程反复重跑。[2] 不过，能恢复任务不代表旧材料永远有效；市场数据的时点仍是判断的一部分。

## 怎样开始，不必先搭开发环境

普通使用者可以从项目的 [GitHub Releases](https://github.com/jundizhou/easy-stock/releases/latest) 下载对应系统的桌面包。官方说明，这条路径不要求先安装 Node.js、Go 或 Python；从源码开发和打包则是另一条路径。[2]

第一次尝试，建议只验证一个小流程：

1. 按仓库的使用帮助准备所需模型连接，以及要访问的内容平台权限。
2. 选择一项只读研究任务，先确认行情或文章能够正常取得。
3. 让 AI 整理少量公开材料，再打开原文，核对它有没有漏掉条件或混淆观点。
4. 手动流程确实可用后，再考虑定时收集和自动复盘。

这些是入门建议，不是本文已经完成的安装实录。不要一开始就导入真实持仓、打开所有自动任务，再用报告是否“像那么回事”判断工具可靠。

## 使用前要看清的三个边界

**本地优先，不等于全程离线。** 文档说明许多资料和记录保存在本机，但行情、内容平台和所选模型服务仍是外部依赖。[2] 尤其使用外部模型时，要检查哪些研究上下文会被发送出去，不能把“本地保存”理解成“所有内容都不会离开电脑”。

**源码公开，不等于允许任意商业使用。** 仓库把自身标为源码可用软件，采用 PolyForm Noncommercial License 1.0.0，并列出商业使用需要另行取得许可的要求。[2] 个人评估与把它接进收费服务是不同的事情，使用前应阅读当前许可证。

**能整理证据，不等于替你承担投资判断。** AI 和第三方数据都可能出错。对它更合适的期待是少做重复搜集、多留可回查的记录，而不是照着一个评分自动买卖。
