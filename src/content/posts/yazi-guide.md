Yazi 是一个运行在终端里的文件管理器。它把文件和文件夹显示成可以用键盘浏览的界面，让你查看内容、选择文件、复制移动和重命名，不必每次都手写一串文件操作命令。[1][2]

可以先把它理解成“终端里的文件浏览窗口”：用途有点像 macOS 的 Finder 或 Windows 的文件资源管理器，但主要通过键盘操作。

如果你经常在终端里写代码、连接服务器，想在同一个工作环境中顺手整理文件，Yazi 会比较有用。如果平时主要用鼠标管理文件，它也不是必须替换掉的东西。

<!--more-->

## 用整理下载目录这件事认识它

假设下载目录里混着截图、PDF 和文本，你想挑出几份素材，复制到项目的 `assets/` 文件夹。

用普通命令完成这件事，你需要先列文件、确认名字，再逐个指定复制路径。Yazi 则提供一个持续打开的浏览界面：移动光标找文件，查看预览，标记要的内容，再进入目标目录粘贴。[1][2]

流程就是：

```text
打开下载目录 → 浏览并预览 → 标记需要的文件 → 复制到目标目录
```

它的价值不在于提供一种新的文件格式，而是让频繁的浏览与搬运更连贯。

## 先装本体，再按需要增加预览能力

macOS 的 Homebrew 安装示例是下面这一行；其他系统按官方安装文档选择相应方式：[5]

```bash
brew install yazi
```

安装后，在自己的终端里运行：

```bash
yazi
```

这会打开当前目录。也可以直接指定一个目录：[2]

```bash
yazi ~/Downloads
```

初次尝试时，先只浏览，不要急着移动或删除重要文件。

Yazi 的部分能力需要其他小工具配合。例如图片、PDF、压缩包等预览有各自的外部依赖，搜索也可能使用额外工具。[5] 因此，“能打开目录”和“所有类型都能预览”不是同一回事。先用好基本浏览，缺什么能力再按官方说明补装，不必一开始就装齐整套依赖。

## 第一步：找到需要的文件

默认可以用方向键浏览，也支持下面这些常用键：[1][2]

| 按键 | 可以先这样记 |
| --- | --- |
| `j` / `k` | 向下 / 向上移动光标 |
| `l` / `h` | 进入文件夹 / 回到上一级 |
| `f` | 按名称过滤当前文件列表 |
| `.` | 显示或隐藏隐藏文件 |
| `q` | 退出 Yazi |

不用先记住这些字母，方向键就能完成基本浏览。这里的过滤是缩小当前列表，和在整个项目里搜索文件内容不是一件事。

移动到文件上后，先看预览区域。如果某一类文件不能预览，要检查对应依赖和终端支持，不能直接理解为文件损坏。打开文件用 `Enter` 或 `o`；它会按配置交给相应程序处理。[1]

## 第二步：挑选并复制到项目里

以刚才的素材整理为例，默认操作可以分成几步：[1]

1. 光标停在需要的文件上，按 `Space` 标记。继续移动，标记其他文件。
2. 按 `y` 复制选中的文件。
3. 进入项目的 `assets/` 目录，确认目标位置，再按 `p` 粘贴。
4. 检查目标目录里是否出现了预期文件。

如果确实要移动而不是复制，第二步换成 `x`，也就是剪切。刚开始练习时更建议先复制，核对目标文件后，再决定是否清理原件。

需要重命名时用 `r`，新建用 `a`；新名称以 `/` 结尾时表示创建目录。[1] 不必先背下几十个快捷键，把浏览、选择和复制用熟就能完成不少任务。

这段操作是默认键位的使用说明，并非本文已完整执行的搬运实录。练习时应选择可以恢复的测试文件。

## 退出以后，终端会停在哪

这是一个很容易遇到的疑问：在 Yazi 里进入项目目录，退出后，为什么终端没有跟着过去？

因为 Yazi 是一个单独运行的程序。你在它里面浏览目录，不会自动改变启动它的终端当前目录。

如果希望“浏览到哪里，退出后终端就留在哪里”，官方提供了一个叫 `y` 的辅助函数。函数是在终端中运行的一小段程序：它启动 Yazi，退出后读取 Yazi 留下的目录，再帮当前终端切过去。[2]

配好这个函数后，用 `y` 启动、按 `q` 退出可以切换目录；不想切换时按大写 `Q`。[1][2] 如果输入 `y` 提示找不到命令，说明还没有配置这段函数，应按 Quick Start 的对应 shell 小节设置，而不是反复重装 Yazi。

## 什么时候再改配置

先保持默认操作，发现具体不顺手的地方再改。Yazi 分别用 `yazi.toml` 管通用行为、`keymap.toml` 管按键、`theme.toml` 管外观。[4]

自己改过按键或装过插件后，本文的默认键位就可能不同。新增少量快捷键时，要区分“追加”和“整体覆盖”，避免为了改一个键把默认映射全换掉。[4]

## 它适不适合你

如果你已经习惯在终端里工作，经常要查看目录、挑选素材或批量整理文件，Yazi 值得试一试。它尤其适合不想在命令和文件浏览窗口之间来回切换的人。

如果你更习惯鼠标，现有文件管理器也已经顺手，就没有必要为了“更专业”换工具。是否合适，先看一次日常任务能不能做得更顺，而不是先比较一串性能宣传。
